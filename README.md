# 手环节拍器

小米手环 9 Pro 上的节拍器应用，使用 Vela JS 开发。

[英文说明](README.en.md)

## 功能

- 速度范围 50–250 BPM，支持滚轮调速和击拍测速。
- 支持 2/4、3/4、4/4、6/8，每拍可设为长振动、短振动或无振动。
- 振动和闪烁可独立开关，拍点显示当前小节位置。
- 四种主题配色，设置保存在本地。
- 界面支持简体中文和英文，跟随系统语言。

## 操作

点击首页中央按钮开始或停止。

| 首页手势 | 功能 |
| --- | --- |
| 左滑 | 调整速度、击拍测速 |
| 上滑 | 选择拍号、设置每拍振动 |
| 下滑 | 选择配色 |
| 右滑 | 退出应用；子页面右滑返回首页 |

点击 BPM 或拍号也可以进入对应页面，长按拍号查看手势指南。进入配置页面会停止播放，返回后需要手动开始。

6/8 的 BPM 以附点四分音符为单位，六个格子按 3＋3 分组。60 BPM 时一小节为两秒。击拍测速时，按两个大拍的节奏点击。

## 安装与限制

当前版本为 **0.5.6**，处于开发测试阶段，尚未上架 AstroBox 或小米官方商店。可以自行构建 debug 包，通过兼容的 RPK 安装工具（如 AstroBox）安装。[`release/astrobox`](https://github.com/kyn0v/xiaomi-band-metronome/tree/release/astrobox) 分支目前仅用于准备发布资料。

- 目标设备为小米手环 9 Pro（336 × 480），其他机型尚未验证。
- 仅前台运行。播放时保持亮屏，退出或离开首页后停止。
- 长振动表示时间较长，不代表力度更强。高速或 6/8 下可能连震，已开始的振动无法立即截断。建议先低速测试。
- 自动化测试不能验证实际振动时序、触摸响应和耗电，仍需真机测试。
- 0.5.5 更换了包名，从此前版本迁移时会安装为新应用，需要重新填写设置。

## 开发

需要 Node.js 20+ 和 npm。重新生成图标时需要 Python 3。

```bash
npm ci --ignore-scripts
npm test
npm run build
```

输出文件：`dist/org.bandmetronome.app.debug.0.5.6.rpk`。

当前构建使用工具链公共调试签名，不是正式发行包。签名、测试和发布流程见 [开发说明（英文）](docs/development.md)。
