# 手环节拍器 / Band Metronome

小米手环 9 Pro 节拍器的源码与 AstroBox 发布资源。
Source code and AstroBox distribution resources for Xiaomi Smart Band 9 Pro.

- **[source](https://github.com/kyn0v/astrobox-xiaomi-band-metronome/tree/source)**：源码、测试和开发说明 / source, tests and development documentation.
- **main**：CreatorConsole 管理的 RPK、商店图片与 `manifest_v2.json` / CreatorConsole-managed distribution files.

请勿合并这两个分支。Do not merge these independent branches.

手动签名构建：**Actions → Build signed RPK → Run workflow → 选择 `source`**。
For a signed build, select **source** in the Run workflow branch picker. Running on
`main` skips the build. The workflow file is mirrored here only so GitHub exposes
the manual-run entry; keep it in sync with the copy on `source`.
